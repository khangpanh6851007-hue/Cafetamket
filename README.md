## 📱 Giới Thiệu Dự Án

**Cà Phê Tám Kết** là một trang web di động (Mobile-first UI 5.0) thiết kế tối ưu hóa trải nghiệm trên smartphone (Android & iOS). Website giúp khách hàng dễ dàng tra cứu thông tin quán, xem menu thức uống, kết nối nhanh chóng qua điện thoại hoặc bản đồ, đặc biệt cập nhật lịch sự kiện âm nhạc định kỳ.

---

## ✨ Tính Năng Nổi Bật

* **🎨 Giao Diện Mobile 5.0:** Thiết kế kính mờ (Glassmorphism), phong cách tối (Dark Mode) hiện đại, mượt mà trên mọi thiết bị di động.
* **🎤 Hát Với Nhau Cuối Tuần:** Tính năng sự kiện đặc biệt cập nhật lịch sinh hoạt âm nhạc Acoustic vào **Chủ Nhật hằng tuần lúc 17:00 chiều**.
* **🗺️ Tích Hợp Google Maps:** Chỉ đường chính xác đến quán chỉ với một cú chạm.
* **📞 Gọi Nhanh 1 Chạm:** Hỗ trợ gọi điện trực tiếp cho chủ quán để đặt bàn hoặc đăng ký bài hát.
* **☕ Menu Thức Uống:** Giới thiệu nhanh các món cà phê đen/sữa đá, bạc xỉu, trà đào cam sả đặc trưng.

## 📱 Hướng Dẫn Sử Dụng trên Acode / TrebEdit (Android / iOS)

Nếu bạn muốn chạy hoặc chỉnh sửa mã nguồn trực tiếp trên điện thoại di động:

1. Tải và mở ứng dụng **Acode** (Android) hoặc **TrebEdit** (Android/iOS).
2. Tạo một file mới và đặt tên là: `index.html`
3. Sao chép toàn bộ mã nguồn của dự án dán vào file `index.html`.
4. Lưu file lại (`Save`).
5. Nhấn nút **Preview** (Xem trước) để trải nghiệm giao diện website ngay trên điện thoại của bạn.
